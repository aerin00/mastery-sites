Spotter protocol

  1. Recall first.
  2. Peek only as a last resort.
  3. Peek the minimum — one hint, not the whole answer.
  4. After peeking, reproduce from memory on the next rep.
  5. Never transcribe. If you keep peeking, you need more reps, not more notes.
