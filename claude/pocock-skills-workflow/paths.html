How entry points, context-window discipline, and convergence differ.

Dimension The Happy Path The Other Paths (Detours & On-Ramps)
When it applies Clear feature scope inside an already-configured repo. Foggy idea, external bug report, failing review, context > 100k, or agent confusion.
