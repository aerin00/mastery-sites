Concepts 4

A harness surrounds the model

The model proposes the next useful step. The harness supplies instructions, context, tools, boundaries, lifecycle control, state, and evidence.

Goal → model decision → tool action → observation → next decision
          ↑                                      │
          └──────────── harness state ───────────┘

Five control layers

LayerQuestionTypical primitives
MindWhat should happen?Instructions, context, memory
HandsHow can it act?Tools, skills, MCP
BoundaryWhat may it do?Sandbox, permissions, approvals
LoopHow does work continue?Hooks, state, retries, subagents
ProofHow do we know?Tests, evaluators, logs, artifacts

Baseline before configuration

Record the working directory, instruction sources, enabled tools, permission mode, expected test command, and current failure. Without a baseline, configuration changes become superstition.

Observable success beats intention

“Be careful” is not measurable. “The forbidden command is denied before execution” is measurable.

Lab

Baseline one real workspace

  1. Choose a real repository or work folder you own.
  2. Record its working directory and active instruction files.
  3. List available tools and current permission mode.
  4. Run the smallest existing verification command, if one exists.
  5. Write one observable harness failure you want to improve.
  6. Break it deliberately: remove the recorded baseline from your notes and try to explain whether a later change helped, then restore it.

Done when: You have a dated baseline naming context, tools, boundaries, verification, and one reproducible failure.

Gotchas 4

trapConfig without a baselineThe agent behaves differently, but you cannot attribute the change or know whether it improved.
trapCapability mistaken for permissionA tool may exist while its action remains blocked by the active boundary.
trapCompletion mistaken for correctnessA polished final response can arrive without any test or observable result.
costInventory without a questionListing everything consumes attention unless each item informs a control decision.
