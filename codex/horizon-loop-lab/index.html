Concepts 4

The project

You will build one ResearchBuildAgent. It accepts a structured goal, plans bounded research and build tasks, verifies artifacts, checkpoints state, recovers from failures, and stops or escalates.

goal → plan → ready task → execute → verify → checkpoint
  ↑                                            │
  └──── resume / replan / escalate / stop ─────┘

Already built

A project folder and a goal, nothing else. This phase adds the contract that every later component must obey.

Typed goal contract

from dataclasses import dataclass, field
from pathlib import Path

@dataclass(frozen=True)
class Goal:
    objective: str
    research_questions: tuple[str, ...]
    deliverables: tuple[str, ...]
    workspace: Path
    max_tasks_per_run: int = 3
    max_attempts_per_task: int = 2
    forbidden_paths: tuple[str, ...] = field(default_factory=tuple)

def validate_goal(goal: Goal) -> None:
    if not goal.objective.strip():
        raise ValueError("objective is required")
    if goal.max_tasks_per_run < 1:
        raise ValueError("max_tasks_per_run must be positive")
    goal.workspace.mkdir(parents=True, exist_ok=True)

Lab

Create the project contract

  1. Create research_build_agent/models.py with the shown Goal dataclass.
  2. Instantiate a goal with two research questions and one Markdown deliverable.
  3. Call validate_goal and print the goal.
  4. Write the allowed workspace and forbidden paths before execution.
  5. Break it deliberately: set max_tasks_per_run=0 and confirm validation rejects it.

Done when: The valid contract prints; the invalid budget raises ValueError before any task runs.

Gotchas 4

trapGoal is only proseThe controller cannot reliably derive budgets, paths, or acceptance rules from an unstructured wish.
trapAutonomy without an ownerThe system reaches an authority boundary but has nobody to receive escalation.
trapSuccess has no witnessThe agent can declare completion without an artifact or passing gate.
costContract covers every imagined caseThe project becomes policy design instead of a working first loop.

Checkpoint 3

What is the reference project?
A ResearchBuildAgent that plans bounded tasks, executes and verifies them, persists state, recovers, and stops or escalates.
Why put budgets in the goal contract?
They turn open-ended autonomy into enforceable limits before work begins.
Recall from later practice: what must survive a restart?
The last verified state, remaining tasks, attempts, evidence, and stop reason.
