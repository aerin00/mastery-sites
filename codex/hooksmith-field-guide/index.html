Concepts 3

ELI5: a hook is a little helper

Imagine Codex is using scissors. A helper wakes up, checks whether the action is safe, and either lets it continue or stops it.

Something happens
        ↓
Hook wakes up
        ↓
Check, act, report

The four-part mental model

QuestionHook partExample
When?EventBefore a tool runs
Which?MatcherOnly Bash commands
Do what?HandlerRun check-command.ps1
Then what?OutputAllow, deny, warn, or add context

Before versus after

PreToolUse can prevent an operation. PostToolUse can inspect what happened, but it cannot undo side effects.

Lab

Describe one hook without code

  1. Choose one repetitive problem in your real Codex work.
  2. Write one sentence: “When ___ happens, automatically ___.”
  3. Name what would count as success.
  4. Break it deliberately: move the proposed check from before the action to after it and identify what can no longer be prevented.

Done when: Your sentence names one event, one action, and one observable success condition.
