⚡ System Architecture Overview

Multi-Surface Autonomous Engineering System

OpenAI Codex operates as a multi-surface autonomous coding agent capable of traversing local workspaces, executing operations inside operating-system sandboxes, patching source trees, and delegating heavy compute tasks to cloud environments. Mastering Codex requires orchestrating five interconnected systems: hierarchical configuration (config.toml), OS sandboxing & approval models, context instruction routing (AGENTS.md), Model Context Protocol (MCP), and procedural Agent Skills.

Key Architectural Invariants

Core execution guarantees enforced across all surfaces.

  • 1. Determinism Over Instruct: Hard boundaries (sandboxes, execpolicy) always supersede soft natural language guidelines in AGENTS.md.
  • 2. Context Hygiene: Progressive disclosure limits baseline token footprint; subagent state isolation prevents prompt degradation.
  • 3. Non-Bypassable Verification: Shell chained vectors are AST-parsed via Tree-sitter to prevent wrapping bypasses.
