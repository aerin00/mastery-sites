      spec-skeleton.md
      # <Project> build spec

## Summary
One paragraph: what it is, who uses it, where it runs.

## Stack
Runtime, framework, storage. App code lives in: src/

## IS NOT (hard boundaries)
- No frontend framework or bundler
- No network calls from the app
- No authentication in v1

## Features
- <feature>: <observable behavior>

## Phases
- P1 <thin slice through every layer>. Done when: <action> shows <result>, and it survives a reload.
- P2 <next slice>. Done when: ...

## Notes
Units, time zones, data formats, anything a test must assume.
