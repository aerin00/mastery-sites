Flat Site Architecture & Master Hub Structuring

In-Context Power Apps Customization & Power Fx Logic

Under governed M365 constraints, custom forms are created directly within list settings. The embedded canvas app relies on the `SharePointIntegration` control to handle panel events. To prevent cross-form data contamination and asynchronous submission failures, developers must orchestrate separate forms for New, Edit, and View modes while enforcing the strict placement of `RequestHide()`.

Copy these exact formulas into your embedded form's `SharePointIntegration` control properties.

`SharePointIntegration.OnNew`
Set(varFormMode, "New");
NewForm(frmCreateItem);
Navigate(scrCreateItem, ScreenTransition.None);
`SharePointIntegration.OnSave`
If(
    varFormMode = "New", SubmitForm(frmCreateItem),
    varFormMode = "Edit", SubmitForm(frmEditItem)
);
`frmCreateItem.OnSuccess` (CRITICAL: RequestHide must be inside OnSuccess!)
ResetForm(Self);
RequestHide(); // Closing the panel BEFORE OnSuccess causes asynchronous submission drop!

Advanced Engineering Pro Tips & Performance Optimization

Deep technical best practices curated for enterprise SharePoint Online architects building under strict low-code governance frameworks.

⚡ OData Trigger Filtering in Power Automate

Never leave a `When an item is created or modified` flow trigger without an OData trigger condition. Without a condition, every minor metadata edit triggers a flow run, consuming API quotas. Use expressions like: 

@equals(triggerOutputs()?['body/ApprovalStatus/Value'], 'Pending Review')
🔒 Item-Level Permission Break Mitigation

Avoid breaking permission inheritance on individual items manually. High counts of unique permissions degrade library performance and cause indexing delays. If necessary during approval cycles, automate temporary locks via Power Automate using the Stop sharing item action.

🏷️ Preserving Author Metadata in SPMT

During shared drive migrations, on-premises Windows accounts (`CORP\jdoe`) must be mapped to corporate Entra ID principal names (`jdoe@company.com`) in a 2-column CSV mapping file. Unmapped accounts default ownership to the executing admin, destroying file provenance.

🎯 Preventing Blank Screen Drops in Custom Forms

When placing `SubmitForm()` in Power Apps, never place `RequestHide()` on the same button line. `SubmitForm()` is asynchronous; executing `RequestHide()` immediately closes the panel before the HTTP POST completes, leading to dropped updates. Always place `RequestHide()` inside the form's `OnSuccess` property!
