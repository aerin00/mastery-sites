Phase 01 · 12 min

The envelope

Stop before you build

Objective. State, from memory, what a citizen may build with Copilot at BC Hydro and what requires an IT Advisor.

Two restriction layers at once

Microsoft Copilot only sees what you can already open. BC Hydro then narrows Power Platform: citizen apps and flows exist only when they start from a SharePoint list or library and only touch that list or library. Copilot inside Word, Excel, Outlook, Teams, Loop, Notebooks, OneDrive, and SharePoint content is allowed. Asking it to publish a standalone app is not.

What you can do

Customize a list form from Integrate. Create a list-originated flow from Workflows or Integrate. Draft flow logic that reads and writes the same list. Use Copilot to design columns, views, Rules, and wording. Submit anything bigger as an IT Advisor brief.

What you cannot do

Standalone Power Apps or flows from the maker portals. Dataverse, SQL, HTTP, APIs, on-prem connectors. Cross-department or enterprise-wide apps. Personal or unmanaged environments. Copilot-generated solutions that leave SharePoint.

Gotchas

Silent failure
A prompt that 'works' in Copilot Chat is not permission. Copilot will draft a Dataverse flow. That draft is still blocked here.
DLP and Restricted SharePoint Search can hide a site from Copilot even when the browser can open it. OneDrive is not hidden by RSS.

Lab · Classify three automations

Setup. You will not open Power Automate. Paper classification only.

  1. Email me when a list item is created.
  2. When Status = Submitted, start approval and write Approved or Rejected back to the same list.
  3. Every night, pull tickets from an external API into the list.

Break. If you marked item 3 as a list flow, you failed the envelope. Item 3 is an IT Advisor request, not a citizen build.

Pass. 1 = Rule. 2 = list-originated flow. 3 = IT Advisor brief. Nothing is built.
