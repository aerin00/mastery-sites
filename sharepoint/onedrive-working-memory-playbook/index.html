Design goal:
Make the current truth obvious, reduce duplicate evidence, and keep personal work separate from authoritative team sources.
Reference Playbook

Structure OneDrive as your personal working memory

The goal is not prettier folders. The goal is a controlled working set where current documents are obvious, stale copies are demoted, authoritative material lives in the right place, and Copilot has less conflicting evidence to reason over.

One current working setKeep only what you actively use.
Links to authorityReference SharePoint originals instead of copying them.
Minimal historical clutterDelete redundant copies and clearly mark retained history.
01 · Core principles

What OneDrive should be

Use OneDrive for

  • Active personal working files
  • Drafts you are responsible for
  • Personal analysis and meeting prep
  • Reusable personal templates
  • Context documents that explain your work

Do not turn it into

  • A dump of email attachments
  • A second copy of SharePoint
  • A permanent archive of every version
  • A mixed pile of official and unofficial information
  • An AI-output knowledge base with no authority labels
Rule of thumb: if an official copy already exists in SharePoint or another governed location, keep the authoritative source there and reference it from OneDrive.

06 · Archive & stale files

Do not treat an Archive folder as an AI exclusion switch

Moving a document into an archive-style folder may help humans, but it should not be treated as a guaranteed semantic instruction to ignore that file.

Still useful?

Keep it only if there is a clear reason.

Retention required?

Move it to the correct official governed location.

Redundant?

Delete it after confirming the current copy.

If an obsolete file must remain

SUPERSEDED - Billing Process - Replaced 2026-04-01.docx
STATUS: SUPERSEDED

Do not use this document for current operational guidance.

Replaced by:
[Current Billing Process]

Effective replacement date:
2026-04-01

Retained for:
Historical reference only
07 · Official vs working

Separate organizational truth from your personal working material

Default: if there is already an authoritative corporate copy, do not create another permanent OneDrive reference copy. 
Did I create this as part of my own work?

YES → OneDrive may be appropriate.

NO → Is there already an authoritative corporate copy?

YES → reference that copy.
      Do not download another permanent copy.

SharePoint

Authoritative truth:

  • Policies
  • Procedures
  • Approved team deliverables
  • Official reference material

OneDrive

Your working memory:

  • Active work
  • Personal analysis
  • Draft deliverables
  • Meeting prep
08 · Working reference

Be strict with 20_Working Reference

  • It does not already have a better authoritative home.

13 · Duplicate audit

Use Copilot to compare suspected duplicates, then decide yourself

Compare these files.

Determine:
1. Which appears to contain the most current information.
2. What substantive changes exist between them.
3. Whether any file contains unique information absent from the others.
4. Which files appear to be redundant copies.

Do not recommend deletion unless the contents are materially represented
in another file.
Copilot can assist with comparison, but deletion remains a human decision.

15 · Five rules

The five rules worth remembering

1. OneDrive = active work

SharePoint is the better home for organizational truth.

2. One logical document = one current file

Use version history instead of endless filename variants.

3. Link instead of copy

Reference official sources rather than duplicating them.

4. Delete useless duplicates

Do not merely bury them in an archive folder.

5. Create one context document

Every major project gets a concise map of purpose, current state, terminology, and source authority.
